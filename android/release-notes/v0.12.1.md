# Runway 0.12.1

0.12.1 is the first published 0.12 release. The 0.12.0 tag stopped in CI before signing, so 0.12.0 was never published; the app is the same.

Runway now works without a plan, and Setup advises instead of refusing.

## Running without a plan

- A fresh install can choose **Log runs without a plan**. Imported and recorded runs go straight to History, with no review step.
- With no plan active, Stats shows the last 12 weeks: weekly distance and running time, runs per week, pace, the longest run and, where imported heart rate is kept, heart rate.

## Setup

- Setup creates every plan it can build, including steep ramps, short lead times and a low marathon base. The review rates it "Steeper than usual" or "Much steeper than usual" and shows the planner's notes; the generated plan still ramps at runway's default weekly rate.
- No confirmation checkboxes, including for two-day schedules. The one that remains is replacing a current goal, because it ends that plan.
- 2 to 7 runs a week, and race dates from 4 weeks out (6 when starting from two weeks of open runs).
- The two-week open-run start now explains that only runs linked to its open days count toward the starting point.

## Plans and Calendar

- Today's planned run can be adjusted or moved, and a run can be added today.
- A passed planned run with no result reads "Not recorded" on any plan, as it does in History.
- "Keep the plan" applies in one tap. Other choices go straight to a preview of the workouts that change.
- "Rebalance this week" now moves distance in 0.5 km steps, so the preview and the result change something.

## Imports and data

- GPX import accepts files of up to 100,000 track points, 32 MB, 300 km or 48 hours, so runs recorded every second import.
- Restore checks the chosen file before disconnecting import sources. A file that can't be restored changes nothing.
- Updating from 0.11.0 or later keeps local data, and backups from 0.11.0 or later can be restored. A future schema change migrates the data or refuses to open it; it never erases it.
- The review sheet closes when the same action completes twice in a row.

## Build

- Android Gradle Plugin 9.4.1, Gradle 9.8.2 and compileSdk 37. The app still targets Android 16 (API 36).
