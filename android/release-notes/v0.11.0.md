Runway 0.11.0 makes weekly routines an explicit progression instead of repeating the endpoint from day one.

- Start a distance or time routine from a recent repeatable week, choose the final weekly goal, and choose the weekly change.
- Review the week-by-week progression before creating it, including the first week, endpoint, and the week that reaches the goal.
- Adjust the routine endpoint or weekly change later from Settings.
- Change a future week's total, or move 0.5 km or 5 minutes between its scheduled run days while keeping the weekly total fixed.
- Planned distance runs use 0.5 km units; recorded actual distances retain their measured precision.

## Hard data cutover

This release intentionally starts a new local database schema. Updating from an earlier Runway version clears the existing on-device Runway ledger. Backups created by earlier schema versions are rejected. There is no in-app migration or compatible restore path from an earlier version into 0.11.0.
