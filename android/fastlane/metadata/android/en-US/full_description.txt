runway is a private, self-hosted running plan and activity review app.

On first launch, choose your self-hosted runway server. The app verifies that address, then opens the
complete runway PWA in a browser-hosted Custom Tab whose controls can collapse while scrolling.
Planning, calendar, run detail, import review, history, stats, settings, and authentication are all
part of the installed app experience. runway does not use an embedded WebView.

Android also retains read access to a user-approved Gadgetbridge GPX export folder and can schedule
bounded checks without broad storage, location, activity-recognition, Play Services, or advertising
permissions. You can share one GPX file to runway from another Android app.

Optionally connect Health Connect to import running and treadmill-running sessions. runway requests
only the exercise-session and workout metrics needed for those runs: distance, heart rate, speed,
steps cadence, and elevation gained. It never writes to Health Connect. Background reads are opt-in
and separately approved; route access is requested per run while the native screen is open. A route
is retained only when the runway server's private route setting allows it; otherwise the server keeps
a redacted summary.

Native folder and share imports use a scoped device credential, stable request ids, bounded reads,
content-based revision checks, and the same review inbox as browser imports. Folder access remains
limited to the directory you choose, and imported activities never change the plan before review.
